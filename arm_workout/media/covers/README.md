# Exercise covers

The 292 JPEGs other than `650.jpg`, `654.jpg`, `666.jpg`, and `690.jpg` are
decoded server covers from `ArmWorkout_Cover_Fetcher/OUTPUT_COVERS`.

Those four IDs returned HTTP 403 and have no matching exercise image in the
Arm Workout 2.4.5 APK. Their JPEGs are generated instructional cover images,
not extracted APK assets or demonstrations of the full motion.
